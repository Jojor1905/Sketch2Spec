# ห้อง พื้น และขอบเขตวัสดุ

## วิธีใช้กับงานเดิม

1. เปิด 3D แล้วกด **แบ่งพื้นตามห้อง** เพื่อแทนพื้นสี่เหลี่ยมเก่าที่ซ้อนกันด้วยพื้นห้องใหม่ ย้อนกลับด้วย Undo ได้
2. เปิด **วัสดุ & งบ** เลือกชนิดวัสดุ แล้วเลือก **ขอบเขตการใช้วัสดุ**
3. เลือกห้องหรือฝั่งผนังให้ครบ แล้วกดปุ่มใช้วัสดุ เมนูจะไม่ทาทั้งแปลนอัตโนมัติเมื่อยังไม่ได้เลือกชิ้นงาน
4. ในขอบเขตห้องเดียว ตั้งชื่อเช่น “ห้องนอน” ได้ ห้องที่เลือกแสดงขอบเน้นใน 3D
5. หากแก้แนวผนังหรือช่องเปิดแล้ว ให้แบ่งพื้นตามห้องใหม่เพื่อให้ขอบเขตห้องตรงกับแปลนล่าสุด

| ขอบเขต | พื้น | ผนัง |
| --- | --- | --- |
| ชิ้นที่เลือก | เปลี่ยนทั้งห้อง รวมส่วนเว้าของห้องรูปตัว L | เปลี่ยนผนังชิ้นนั้นทั้งสองฝั่ง |
| ผิวที่คลิก | ไม่ใช้กับพื้น | เปลี่ยนเฉพาะช่วงที่ติดกับห้องนั้น เลือกจากชื่อห้องได้ กรอบม่วงแสดงขอบเขตก่อนทา |
| ห้องเดียว | เปลี่ยนพื้นของห้องนั้น | เปลี่ยนเฉพาะฝั่งและช่วงผนังที่หันเข้าห้องนั้น |
| ทั้งแปลน | เปลี่ยนพื้นทุกห้อง | เปลี่ยนผนังทุกชิ้นทั้งสองฝั่ง |

## เงื่อนไขการแบ่งห้อง

- ใช้ผล wall/door/window จากโมเดลเดิมเป็นขอบเขต แล้ว flood fill หาเฉพาะพื้นที่ปิด ไม่นับพื้นที่ด้านนอกภาพเป็นห้อง
- หนึ่งพื้นที่ปิดเป็นหนึ่งวัตถุห้อง ภายในเก็บชิ้นส่วนสี่เหลี่ยมที่ไม่ทับกันเพื่อแสดงห้องเว้า รูปตัว L หรือช่องเว้น โดยไม่ปูทับห้องข้าง ๆ
- ประตูและหน้าต่างถือเป็นส่วนของขอบห้องเพื่อแยกห้องสองฝั่งช่องเปิด การตรวจจับช่องเปิดผิดยังมีผลกับการแบ่งห้อง
- พื้นเก่าไม่ถูกวางซ้อนลงไปอีก การแบ่งใหม่แทนพื้นเดิม และใช้พื้นที่ทับซ้อนมากที่สุดเพื่อรักษาชื่อและวัสดุเดิม หากพบศูนย์ห้องจะเก็บงานเดิมไว้
- หลังแบ่งห้อง การวาดพื้นใหม่ทับพื้นเดิมจะเลือกพื้นเดิมแทน การย้ายหรือปรับขนาดที่ทำให้พื้นชนกันจะคืนค่าก่อนแก้ พร้อมข้อความแจ้ง
- ผนังร่วมเก็บวัสดุแยกสองฝั่ง และแยกช่วงตามห้อง ไม่ใช้ materialId ค่าเดียวแทนทั้งผนัง การทาห้องใหม่จึงไม่เปลี่ยนสีอีกฝั่งหรือช่วงของห้องข้างเคียง
- Undo/Redo ไฟล์สำรอง และการเปิดงานกลับมาเก็บทั้งรูปทรงห้อง ชื่อ และวัสดุแต่ละฝั่ง
- พื้นที่พื้นสำหรับประมาณราคาใช้พื้นที่รูปทรงจริง ไม่ใช้กรอบครอบของห้องเว้า พื้นที่ผนังแยกตามช่วงและฝั่ง (ยังเป็นพื้นที่รวมก่อนหักช่องเปิด)

## ข้อจำกัดเกี่ยวกับ AI

`best.pt` ยังมีเพียง door, wall, window และไม่ได้เปลี่ยนหรือเทรนใหม่ ห้องเป็นผลประมวลผลเรขาคณิตหลัง AI ไม่ใช่ room segmentation จากภาพ

หากผนังขาด ห้องเชื่อมโล่งไม่มีขอบแบ่ง หรือกรอบตรวจจับผนังเอียง/โค้งไม่ตรงแนว การแบ่งพื้นที่ปิดอาจรวมหลายห้องหรือไม่พบห้อง ต้องตรวจแก้แนวก่อน ระบบยังไม่รู้เองว่าพื้นที่ใดเป็นห้องนอนหรือห้องครัว

หากต้องการให้โมเดลรู้รูปทรงห้องโดยตรง ขั้นถัดไปคือเตรียม annotation ห้อง/พื้นเป็น mask หรือ polygon รวมถึงแปลนที่ผนังขาด ห้องเว้า ผนังเอียง และพื้นที่เปิดเชื่อมกัน พร้อมกำหนดเกณฑ์แบ่งห้องในชุดข้อมูลให้เหมือนกัน งานนี้ไม่ได้แก้โมเดล

## ทดสอบ

```bash
node tests/rooms.cjs
node tests/floor-plan-repair.cjs

```

ทดสอบสามห้องที่ใช้ผนังร่วมกัน แยกฝั่งและช่วง พื้นเก่าซ้อนกัน ห้องรูปตัว L การเลือกผ่านส่วนเว้า ขอบเขตทั้งแปลน Undo การประมาณพื้นที่ และการเก็บข้อมูลกลับมาใช้

## การแก้ช่องว่างและผิวผนัง

- พื้นใช้พิกัดขอบผนังจริงแทนการปัดลงตาราง จึงชิดผนังแม้พิกัดมีทศนิยม
- กรอบสัญลักษณ์ประตู/หน้าต่างที่หาแนวผนังใกล้เคียงได้ ใช้ความหนาของแนวนั้นเป็นขอบห้อง เพื่อลดช่องว่างจากวงสวิงประตู
- คลิกด้านข้างผนังจะตั้งขอบเขตเป็นผิวด้านเดียวและช่วงห้องที่คลิก หากฝั่งเดียวมีหลายห้องแต่ยังไม่เลือกช่วง ต้องเลือกผิวจากชื่อห้องก่อนทา
- กรอบม่วงแสดงผิวที่จะทาจริง รวมกรณีทั้งห้อง ส่วนผนังทั้งชิ้น/ทั้งแปลนยังเลือกได้อย่างชัดเจน
- ปุ่มแบ่งพื้นตามห้องและขั้นตอนรับผล AI กรองประตู/หน้าต่างที่กรอบเกือบเหมือนกัน โดยให้วัตถุที่ลงวัสดุแล้วหรือมี confidence สูงกว่าคงอยู่ การแยกประเภทผิดยังต้องตรวจทาน ไม่ใช่การเพิ่มความแม่นยำของโมเดล
- สำหรับงานเก่า กดแบ่งพื้นตามห้องใหม่เพื่อใช้ขอบพื้นชุดใหม่ (Undo ได้)

ทดสอบเพิ่มเติม: `backend/.venv/bin/python backend/test_surfaces.py` ตรวจพื้นพิกัดทศนิยม ประตูซ้ำ การคลิกผิวจริง กรอบตัวอย่าง และทาสองช่วงของผนังชิ้นเดียวโดยไม่เปลี่ยนอีกฝั่ง ภาพอยู่ใน `backend/test_results/surface-before-paint.png` และ `surface-after-paint.png`

## เมนูทาสีผนังแบบ 3 ขั้นตอน

1. เปิด **วัสดุ & งบ → สีทาผนัง** แล้วเลือก **ทั้งห้อง / ผนังเดียว / ทั้งแปลน** และชื่อห้อง
2. ถ้าเลือกผนังเดียว ให้กดหมายเลขบนภาพห้องหรือปุ่มหมายเลขด้านล่าง สีม่วงบนโมเดลแสดงผิวที่เลือก จากนั้นเลือกสี/วัสดุ
3. ตรวจข้อความสีและบริเวณ แล้วกด **3. ทาสีผนัง** การเลือกสีอย่างเดียวยังไม่เปลี่ยนโมเดล

ไม่ต้องเลือกวัตถุผนังใน 3D ก่อนทาทั้งห้อง และเมื่อเปลี่ยนจากพื้นไปผนังจะใช้ห้องที่กำลังเลือกอยู่ สีที่เลือกคงเดิมเมื่อเปลี่ยนผนังหรือห้อง ปุ่มทาทั้งสองฝั่งของผนังชิ้นเดียวอยู่ในตัวเลือกเพิ่มเติม การปรับขนาด/หมุนลายในโหมดผนังเดียวจำกัดเฉพาะช่วงผิวที่เลือก

การเลือกพื้นเดิมยังใช้ได้ รวมการเลือกจากเมนูวัตถุในโมเดล พื้นรูปตัว L และการตั้งชื่อห้องในหมวดพื้น

ตรวจเพิ่มเติมด้วย `backend/.venv/bin/python backend/test_wall_paint_ux.py`: เริ่มจากทาพื้นแล้วสลับไปผนัง เลือกผนังจากภาพ กดใช้สีจริง ตรวจไม่เปลี่ยนพื้น/ห้องข้างเคียง Undo/Redo เปลี่ยนห้องโดยคงสี และหน้าจอมือถือ
