## ติดตั้งบนเครื่องใหม่ (Windows / VS Code)

1. ติดตั้ง **Python 3.11 แบบ 64-bit** และ **Node.js 24** แล้วปิดเปิด VS Code ใหม่
2. แตก ZIP ก่อน และเปิดโฟลเดอร์ที่มี `package.json` ใน VS Code (อย่าเปิดแค่โฟลเดอร์ครอบด้านนอก)
3. เปิด Terminal แบบ PowerShell แล้วติดตั้งครั้งแรก:

```powershell
npm.cmd run setup
```

4. เมื่อติดตั้งเสร็จ เปิดทั้ง Backend และ Frontend ด้วยคำสั่งเดียว:

```powershell
npm.cmd run local
```

5. รอข้อความ Ready แล้วเปิด http://localhost:3000/login

บัญชี Demo สำหรับใช้บนเครื่องตัวเอง: **admin1234 / admin1234**
กด Ctrl+C เพื่อปิดทั้งสองระบบ ครั้งถัดไปใช้แค่ `npm.cmd run local`
ไม่ต้อง Activate virtual environment ไม่ต้องใช้ไฟล์ .bat และไม่ต้องเปลี่ยน ExecutionPolicy
macOS/Linux ใช้คำสั่งเดียวกันโดยเปลี่ยน `npm.cmd` เป็น `npm` และติดตั้ง Python 3.11 ก่อน

### คำสั่งติดตั้งทำอะไรบ้าง

- ตรวจเวอร์ชัน Node.js ตามข้อกำหนดของแพ็กเกจ PDF: 22.13+ ในสาย 22 หรือ 24+
- เลือก Python 3.11 แบบ 64-bit และสร้าง `backend/.venv` บนเครื่องปลายทาง
- ถ้าเจอ virtual environment จากเครื่องเดิม จะเก็บไว้เป็น `.venv.backup-...` และสร้างใหม่
- ติดตั้ง PyTorch แบบ CPU บน Windows/Linux จึงไม่จำเป็นต้องมี NVIDIA/CUDA
- ติดตั้งแพ็กเกจ Frontend ด้วย `npm ci` จาก lockfile
- สร้าง `.env.local` และ `backend/.env` จากตัวอย่างเฉพาะเมื่อยังไม่มี
- โหลด `best.pt` และลองประมวลผลภาพว่างหนึ่งภาพก่อนแจ้งว่าติดตั้งเสร็จ

ต้องใช้อินเทอร์เน็ตในการติดตั้งครั้งแรกและมีพื้นที่ว่างสำหรับแพ็กเกจ AI
โฟลเดอร์โปรเจกต์ต้องเขียนไฟล์ได้ แนะนำให้แตกไปโฟลเดอร์ผู้ใช้ เช่น `C:\Projects\Sketch2Spec`

### ถ้าเคยติดตั้งเวอร์ชันเก่า

ถ้า `.env.local` เดิมชี้พอร์ต 8000 หรือค่าตั้งค่า Login ไม่ตรงกัน ให้สำรองและตั้งค่าเป็น Local Demo ใหม่ด้วย:

คำสั่งนี้สำรองไฟล์ตั้งค่าเดิมไว้เป็น `.backup-...` ก่อนเขียนใหม่ ใช้สำหรับรันในเครื่องตัวเอง
ค่าตั้งค่า Production ยังอธิบายใน `docs/AUTHENTICATION.md`

### ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| npm หา package.json ไม่เจอ | เปิด Terminal ในโฟลเดอร์ที่มี package.json |
| npm.ps1 ถูกบล็อก | ใช้ `npm.cmd` ตามคำสั่งด้านบน |
| ไม่พบ Python 3.11 | ติดตั้ง Python 3.11 แบบ 64-bit แล้วเปิด VS Code ใหม่ |
| สร้าง venv ไม่สำเร็จ | ตรวจว่าโฟลเดอร์เขียนได้และ Python ทำงาน; หาก Python จาก Store มีปัญหาให้ใช้ตัวติดตั้งจาก python.org แล้วรัน setup ใหม่ |
| Port 3000 หรือ 8001 is busy | ปิด Terminal ของเซิร์ฟเวอร์เก่าด้วย Ctrl+C แล้วรันใหม่; ตัวเปิดจะไม่ฆ่าโปรแกรมอื่นและไม่เปลี่ยนพอร์ตเอง |
| Login ขึ้น Untrusted request origin | เปิด localhost:3000 หรือ 127.0.0.1:3000 และตรวจ AUTH_ALLOWED_ORIGINS ทั้งสองไฟล์ |
| Service unavailable | ดูข้อความใน Terminal ว่า Backend เปิดสำเร็จ และตรวจพอร์ตใน .env.local |
| pip/npm ดาวน์โหลดไม่ได้ | ตรวจอินเทอร์เน็ต/Proxy แล้วรัน setup อีกครั้ง |

### ตั้งค่าและเปิดเอง (กรณีไม่ใช้ local launcher)

ไฟล์ `.env.local`:

```env
DETECTION_API_URL=http://127.0.0.1:8001
AUTH_ALLOWED_ORIGINS=http://localhost:3000,http://127.0.0.1:3000
```

Backend ใน Terminal แรก (หลัง setup):

```powershell
.\backend\.venv\Scripts\python.exe -m uvicorn main:app --app-dir backend --env-file backend/.env --host 127.0.0.1 --port 8001
```

Frontend ใน Terminal ที่สอง:

```powershell
npm.cmd run dev -- --hostname 127.0.0.1 --port 3000
```

ตรวจ Backend ที่ http://127.0.0.1:8001/health โมเดลอยู่ที่ `backend/best.pt`
การแก้ชุดนี้สำหรับส่งโปรเจกต์ไปติดตั้งและรันบนเครื่องอื่น โดยแต่ละเครื่องเปิดเซิร์ฟเวอร์ของตนเอง
หากต้องการเปิดข้ามเครือข่ายหรือเผยแพร่บน Vercel ต้องตั้ง Backend และระบบ Auth สำหรับ HTTPS ตามคู่มือแยก

## Stage 4 — วัสดุและงบประมาณ

เปิดมุมมอง 3D แล้วกดปุ่ม **วัสดุ & งบ**

รองรับวัสดุสำหรับ:

- ผนัง: สีขาวด้าน คอนกรีต อิฐ ไม้กรุ และหิน
- ประตู: สีขาว ไม้โอ๊ก และกรอบดำ
- หน้าต่าง: กระจกกรอบเงิน กรอบดำ และกรอบไม้
- พื้น: กระเบื้องสีอ่อน พื้นไม้ ปูนขัดมัน และกระเบื้องสีเข้ม

การใช้งาน:

- ใช้วัสดุกับวัตถุที่เลือก
- ใช้วัสดุกับวัตถุประเภทเดียวกันทั้งหมด
- เปลี่ยนวัสดุพื้นแบบทันที
- วัสดุของผนัง ประตู และหน้าต่างถูกบันทึกในโปรเจกต์
- วัสดุพื้นถูกบันทึกใน IndexedDB พร้อมโปรเจกต์
- Undo/Redo ใช้กับการเปลี่ยนวัสดุของวัตถุได้

## การประมาณราคา

ต้องกำหนดมาตราส่วนจริงก่อน ระบบจึงจะคำนวณราคาได้

- ผนังคำนวณจากความยาว × ความสูง แยกตามฝั่งและช่วงที่ใช้วัสดุ หากใช้ทั้งชิ้นจะรวม 2 ด้าน ยังไม่หักพื้นที่ช่องเปิด
- ประตูคำนวณเป็นจำนวนชิ้น
- หน้าต่างคำนวณตามพื้นที่โดยประมาณ
- พื้นคำนวณจากพื้นที่จริงของชิ้นส่วนห้อง รวมรูปตัว L หรือพื้นสี่เหลี่ยมที่สร้างเอง
- ส่งออกรายการวัสดุและราคาเป็นไฟล์ CSV ได้

ราคาเป็นค่าเริ่มต้นสำหรับการสาธิต สามารถแก้ไขได้ใน:

```text

```

## วัสดุสมจริง (Stage 4.1)

เวอร์ชันนี้รองรับทั้ง **procedural texture** และ **image-based PBR texture** ที่จัดเก็บอยู่ภายในโปรเจกต์
จึงยังสามารถพกโปรเจกต์ไปใช้เครื่องอื่นได้ โดยไม่ต้องเชื่อมต่อบริการ texture ภายนอก

สิ่งที่เพิ่มเข้ามา:

- ผนังมีลายผิวแบบ สีทา / คอนกรีต / อิฐ / ไม้ / หิน
- พื้นมีลาย กระเบื้อง / ไม้ / ปูนขัดมัน
- ประตูมีผิวไม้และผิวโลหะ
- หน้าต่างมีเอฟเฟกต์กระจกพร้อมกรอบ
- ปรับ repeat texture ตามขนาดวัตถุอัตโนมัติ เพื่อไม่ให้ลายยืด
- ใช้ `MeshPhysicalMaterial` เพื่อให้แสงและผิววัสดุดูสมจริงขึ้น
- มีภาพตัวอย่างลายวัสดุ (Thumbnail Preview) ในแผงวัสดุ ก่อนนำไปใช้กับโมเดล

หมายเหตุ:

- ระบบนี้เป็นแบบ **lightweight realistic** เหมาะกับการรันบนเว็บและเครื่องทั่วไป
- ถ้าต้องการระดับสมจริงมากกว่านี้ ภายหลังสามารถต่อยอดเป็น HDRI + PBR texture จริงได้

## สร้างพื้นเอง (Stage 4.2)

ปัจจุบันระบบสร้างพื้นจากขอบเขตห้องปิดหลัง AI และมีปุ่ม **แบ่งพื้นตามห้อง** สำหรับคำนวณใหม่ ผู้ใช้ยังสร้างพื้นสี่เหลี่ยมเองได้ตามขั้นตอนด้านล่าง โดยระบบจะป้องกันการเพิ่มพื้นทับห้องเดิม

วิธีใช้:

1. เลือกเครื่องมือ **พื้น** หรือกด `5` / `F`
2. คลิกค้างแล้วลากบนแบบแปลนเพื่อสร้างพื้นสี่เหลี่ยม
3. กลับไปที่เครื่องมือ **เลือก** เพื่อย้ายพื้น
4. ลากจุดมุมสีม่วงเพื่อปรับความกว้างและความยาว
5. เปิด **วัสดุ & งบ > พื้น** เพื่อใช้วัสดุกับพื้นชิ้นที่เลือกหรือพื้นทั้งหมด

คุณสมบัติ:

- พื้นแต่ละชิ้นเป็นวัตถุแยกกัน
- ย้าย ปรับขนาด ทำสำเนา ลบ Undo และ Redo ได้
- ใช้วัสดุคนละแบบในแต่ละห้องได้
- พื้นใหม่ใช้วัสดุเริ่มต้นจากวัสดุพื้นล่าสุดที่ตั้งไว้
- ไม่มีพื้นขนาดใหญ่ปูเต็มแบบแปลนอัตโนมัติ


## Real Texture System (Stage 5.1)

เพิ่มวัสดุไม้จากภาพจริงที่ผู้ใช้ส่งมา พร้อมสร้างแผนที่ PBR สำหรับใช้งานบนโมเดล 3D:

- `walnut_basecolor.jpg` — สีและลายไม้จริง
- `walnut_normal.jpg` — รายละเอียดเสี้ยนและร่องไม้เมื่อรับแสง
- `walnut_roughness.jpg` — ควบคุมความด้านและความเงา
- `walnut_ao.jpg` — แผนที่เงาร่องสำหรับต่อยอด

วัสดุใหม่:

- ไม้กรุวอลนัตจริงสำหรับผนัง
- ประตูวอลนัตลายจริง
- พื้นไม้วอลนัตจริง

การใช้งาน:

1. เปิด **วัสดุ & งบ**
2. เลือกหมวดผนัง ประตู หรือพื้น
3. เลือกวัสดุที่มีป้าย `REAL`
4. กดใช้กับวัตถุที่เลือกหรือใช้กับทั้งหมด
5. กดไอคอนขยายบนภาพตัวอย่าง เพื่อดูพื้นผิวแบบซูมใกล้

ระบบจะปรับการทำซ้ำของลายตามขนาดวัตถุ และหมุนแนวลายสำหรับประตูโดยอัตโนมัติ เพื่อลดปัญหาลายไม้ยืดผิดสัดส่วน

- Save Favorites: บันทึกวัสดุโปรดใน Browser และกรองดูเฉพาะรายการโปรดได้
- Texture Preview: เปิดดูพื้นผิวแบบซูมใกล้ พร้อมรองรับ Real Texture และ Procedural PBR
- Texture Controls: ปรับขนาดลายและหมุนทิศทางลายของวัตถุที่เลือกได้
- Lighting Presets: กลางวัน, อบอุ่น, กลางคืน และสตูดิโอ
- Real-time Calculation: เมื่อใช้วัสดุ ระบบคำนวณราคาใหม่จากวัตถุและพื้นที่ที่มีมาตราส่วนจริงทันที


## ตั้งมาตราส่วนแบบง่าย

- ไม่จำเป็นต้องเลือกกำแพงก่อน ระบบจะเลือกกำแพงที่ยาวที่สุดให้อัตโนมัติ
- กรอกความยาวจริงเพียงครั้งเดียว แล้วกด **ใช้กับทั้งแปลน**
- เลือกกำแพงอื่นเองได้ เมื่อต้องการใช้ระยะอ้างอิงที่แม่นยำกว่า
- มีปุ่มลัดความยาว 3, 4, 5 และ 6 เมตร
- กด Enter หลังกรอกตัวเลขเพื่อยืนยันได้
- ตั้งมาตราส่วนเพียงครั้งเดียวต่อหนึ่งแปลน

## งานเก่าที่มีฝ้า

เครื่องมือสร้างฝ้าและหมวดวัสดุฝ้าถูกเอาออกตามผลทดสอบผู้ใช้ ไฟล์งานเก่ายังเปิดฝ้าเดิมได้ เลือกผ่านรายการชิ้นงานเพื่อลบหรือปรับคุณสมบัติได้

## การเริ่มคำนวณราคา

- โมเดล 3D ที่สร้างจากผลสแกนจะแสดงวัสดุเริ่มต้นเพื่อให้ดูรูปทรงได้ แต่ **ยังไม่คิดราคา**
- ระบบจะเริ่มเพิ่มรายการลง Budget/BOQ เมื่อผู้ใช้เลือกวัสดุและกดใช้กับวัตถุที่เลือก หรือใช้กับทั้งหมด
- พื้นและห้องที่สร้างใหม่ก็จะยังไม่คิดราคา จนกว่าจะเลือกและใช้วัสดุจริง
- ยอดรวมและไฟล์ CSV จะรวมเฉพาะวัตถุที่ผู้ใช้ยืนยันวัสดุแล้วเท่านั้น

## การเก็บงานและการทดสอบฟังก์ชัน

- แอปบันทึกงานล่าสุดลงเบราว์เซอร์เดิมอัตโนมัติ พร้อมแสดงสถานะการบันทึก
- **สำรองโปรเจกต์** ดาวน์โหลดไฟล์ `.sketch2spec.json` ซึ่งเก็บภาพ วัตถุ มาตราส่วน และวัสดุที่ใช้
- **เปิดโปรเจกต์** นำไฟล์สำรองกลับมาแก้ไขได้ โดยไม่ต้องตรวจจับ AI ใหม่
- การเริ่มใหม่และแทนที่ผลตรวจจับต้องยืนยันก่อน งานเดิมจะยังอยู่หากเลือกไฟล์ผิดหรือ AI ล้มเหลว
- **ยกเลิกการรอผล** หยุดรอในหน้าเว็บโดยเก็บงานเดิมไว้ งาน AI ที่เริ่มประมวลผลบน backend อาจทำต่อจนเสร็จ
- สำรองไฟล์ก่อนล้างข้อมูลเบราว์เซอร์หรือย้ายไปใช้เบราว์เซอร์/เครื่องอื่น

ทดสอบการใช้งานผ่าน Chrome ด้วยโปรไฟล์ทดสอบแยก (เปิด frontend และ backend ก่อน):

```bash
backend/.venv/bin/python -m pip install -r backend/requirements-test.txt
backend/.venv/bin/python backend/test_browser_workflow.py /path/to/floor-plan.jpg
```

ใช้ภาพแปลนที่โมเดลตรวจพบวัตถุได้ การทดสอบครอบคลุม AI จริง การรักษางานเมื่อเกิดข้อผิดพลาด
Undo/Redo มาตราส่วน วัสดุ CSV สำรอง/เปิดโปรเจกต์ PDF และขนาดจอมือถือ
ภาพผลทดสอบอยู่ใน `backend/test_results/`

### การแก้ไขใน 3D

- คลิกเลือกวัตถุจะไม่เปลี่ยนตำแหน่งหรือเพิ่มรายการ Undo

ทดสอบการโต้ตอบใน 3D ด้วยแปลนจำลองสำหรับทดสอบ (ไม่แก้ไขโมเดล AI):

### แก้ผล AI และหมุนดูโมเดล

- หลังยืนยันภาพ สามารถกด **เพิ่มผนัง / เพิ่มประตู / เพิ่มหน้าต่าง** ได้ทันที ทั้งก่อนและหลัง Run AI Detection
- คลิกวัตถุเพื่อเลือก ลากเพื่อย้าย ใช้จุดจับเพื่อปรับขนาด แล้วกด **ลบวัตถุที่เลือก** หรือ Delete เพื่อลบ
- ใช้ **ย้อนกลับ / ทำซ้ำ** เพื่อแก้ไขเมื่อกดผิด และเปิด **รายละเอียด / ขนาดจริง** เมื่อต้องการตั้งมาตราส่วน
- 3D เปิดในโหมด **หมุนดู 360°**: ลากเมาส์ซ้ายเพื่อหมุน ลากเมาส์ขวาเพื่อเลื่อน และใช้ล้อเมาส์เพื่อซูม
- กด **แก้ไขวัตถุ** เพื่อเลือกหรือย้ายวัตถุ และ **คืนมุมกล้อง** หากหลงมุมมอง

ทดสอบปุ่มแก้ไข 2D และการหมุนรอบโมเดลด้วยเมาส์จริง:

```bash
backend/.venv/bin/python backend/test_editing_ux.py
```

### การปรับตามผลทดสอบ Edit_SCG.pdf

- ภาพแปลนต้นฉบับแสดงที่มุมซ้ายบนของ 3D และย่อ/ขยายกรอบได้
- โหมดหมุนดู: คลิกหนึ่งครั้งเพื่อเลือกชิ้นงาน ลากบนโมเดลเพื่อหมุน ลากบนพื้นห้องเพื่อเลื่อนกล้อง
- ปุ่มลูกศรหรือ WASD เลื่อนกล้อง; โหมดแก้ไขวัตถุใช้ลากย้ายวัตถุแทนกล้อง
- มีรายการเลือกชิ้นงานสำหรับพื้นหรือผนังที่ถูกบัง และปุ่มลบชิ้นที่เลือก
- สร้างพื้น/ห้องแล้วกลับเครื่องมือเลือกอัตโนมัติ ห้องใหม่มีพื้นเมื่อขอบเขตปิด และส่วนผนังที่ใช้ร่วมกับผนังเดิมไม่สร้างทับซ้ำ
- หมวดวัสดุแยกประตูและหน้าต่าง; ใช้กับที่เลือกปรับเฉพาะชิ้น ส่วนตัวปรับขนาด/หมุนลายต้องเลือกชิ้นงานก่อน
- เอาเครื่องมือสร้างฝ้าออกจากเมนูและปุ่มลัด แต่ยังเปิดและลบฝ้าในไฟล์งานเก่าได้
- ผล AI ผ่านการลบผนังซ้ำแบบระมัดระวังและเติมพื้นจากขอบเขตปิด หรือกด **แก้ผนังซ้ำ / แบ่งพื้นตามห้อง** ในรายละเอียด 2D สำหรับงานเดิม ย้อนกลับการแก้ด้วยปุ่มนี้ได้

ข้อจำกัดของโมเดล: `best.pt` มีคลาส `door`, `wall`, `window` เท่านั้น พื้นใหม่เป็นการคำนวณพื้นที่ปิดจากกรอบผนังและช่องเปิด ไม่ใช่คลาสที่ AI ตรวจจับ หากผนังขาดหรือแนวซับซ้อนต้องตรวจและปรับผลก่อน ห้องเว้าเก็บเป็นวัตถุเดียว โดยรวมชิ้นรูปทรงที่ไม่ทับกันภายในห้อง การตรวจขอบเขตห้องจากภาพโดยตรงต้องมีข้อมูลห้อง/พื้นสำหรับฝึกโมเดลเพิ่มเติม ไม่ได้แก้ไขหรือเทรนโมเดลในงานนี้

### พื้นและวัสดุแยกตามห้อง
